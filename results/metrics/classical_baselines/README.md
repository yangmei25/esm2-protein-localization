# Classical baseline results

These files are generated by:

```bash
python scripts/train_classical_baselines.py --overwrite
```

- `metrics.csv` and `metrics.json` contain validation and exploratory test
  metrics for Logistic Regression and Random Forest.
- `predictions.csv` contains local protein-level probabilities and predictions;
  it is Git-ignored because source-data redistribution terms are unresolved.
- `run_config.json` records coverage, feature names, split counts, fixed
  settings, and software versions.

Both classifiers use the same 35 full-length amino-acid composition and
Kyte–Doolittle hydrophobicity features. Generated `.joblib` model files are
kept in the Git-ignored `results/models/classical_baselines/` directory.
